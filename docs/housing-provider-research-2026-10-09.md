## Recommendation

**ImmoScout24 Search & Exposé API, applied for as a content partner** — it is the *only* verified, legitimate path to genuine German-wide rental listings:

1. **Coverage & fit**: Germany's largest rental portal; the Search API natively supports exactly our query model — `realestatetype=ApartmentRent`, **region and radius search** (`/search/v1.0/search/radius?realestatetype=ApartmentRent&geocoordinates=lat;lon;radius`), JSON responses with cold/warm rent, rooms, living space, coordinates, address, images, and a direct link to each Exposé — a near 1:1 mapping onto our `HousingListing` type.
2. **Expected costs (honest)**:
   - **Sandbox: free** (key self-service, test data).
   - **Production Search API: not free, price not published** — quoted individually at "booking" (ToU §3.1). Scale reference: their only published list (Listing API) starts at **€59 net/mo for 0–20k calls** and €249 net/mo for 40–80k. A realistic volume for our app (server-side, cached per query) is likely in the low tiers, but **treat any number below a written quote as speculation**.
   - No other fees were published (no onboarding/subscription fee found in ToU).
3. **Limitations we must design around (all from their ToU, verifiable)**:
   - **24-hour data retention** (§7.2): IS24 data may only be stored for 1 day. → Our saved-listings snapshots **cannot** persist IS24 data; save-flow for IS24 listings must store a reference (id + URL) and re-fetch on display, or the listing must be excluded from permanent saving.
   - **No own database / no evaluations** (§7.1): on-demand presentation for the end user only — we may not cache into a permanent index or build price analytics from IS24 data.
   - **Mandatory branding** (§7.7/§8): results must carry "In cooperation with ImmoScout24" + logo + link to is24.de, using their exact templates.
   - **Contact channel restricted** (§9.4): landlord contact only via their "contact request" API or a link to the Exposé — no email harvesting.
   - **Approval risk** (§2.1, Search intro): "content partners … not for data delivery use cases" and IS24 "may decline at any time … without reasons". Our use case (publicly displaying IS24 rental data on a website) is precisely the "customer website / content partner" use case they describe, so it should be admissible — but **approval is not guaranteed**.
   - **Contract penalties** (§10): up to €50,000 per culpable breach of data-use/branding rules — the integration must be strict.
   - Prices adjustable once per year (objection right if >15%); termination for non-pay uses at any time in text form.
4. **Why not the others**: Immowelt/WG-Gesucht/Kleinanzeigen/Immonet expose **no legitimate self-service search access** (verified); open data is statistics or a dead 2015 snapshot; niche furnished feeds can't be verified and barely match our audience; scrapers are out of scope by rule.
